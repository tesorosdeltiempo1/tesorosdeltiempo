# Tesoros del Tiempo — Detalle de objeto / 1 Peseta 1988

Primera iteración de la página de detalle editorial.

## Archivos

- `producto.html` — estructura y contenido.
- `producto.css` — identidad visual, responsive y motion.
- `producto.js` — reveal on scroll, parallax suave y galería horizontal.

## Integración

Copia estos tres archivos a la raíz del proyecto actual:

- `producto.html`
- `producto.css`
- `producto.js`

Desde la home puedes enlazar una tarjeta de producto a:

`producto.html`
